📝 Instructions

This is a test page designed to help you test the Blur App Chrome extension. Follow these steps:

  1. Install the Extension: Load the extension in Chrome from chrome://extensions/
  2. Click the Extension Icon: Find the Blur App icon in your Chrome toolbar
  3. Enable Selection Mode: Click "Enable Selection Mode" in the popup
  4. Select Areas to Blur: Click and drag on this page to select areas
  5. Test Persistence: Scroll down and back up, or refresh the page
  6. Remove Blurs: Right-click on any blur region to remove it
✅ Success Criteria: Blur regions should remain in the exact same position even after scrolling or refreshing the page.
